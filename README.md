# ✨ Glow & Glam

### Where Beauty Meets Confidence

Glow & Glam is a modern and elegant beauty website designed for a skincare and fashion brand. 
The website provides a premium digital experience for clients looking for beauty, skincare, 
hair, nails, bridal, and fashion services.

## 🌸 Features

- 🏠 Home page with elegant hero section
- 💆 Skincare & beauty services
- 👰 Bridal services
- 👗 Fashion section
- 🖼️ Gallery
- 📞 Contact section
- 📅 Book Now call-to-action
- 📱 Clean and responsive design

## 🎨 Design

The website uses a soft, minimal, and luxurious aesthetic with:

- Neutral cream background
- Elegant typography
- Warm brown accents
- Clean navigation
- Premium fashion & beauty imagery

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
